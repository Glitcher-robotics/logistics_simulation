# 제품 목표와 MVP 범위

회사 내 AMR·무인지게차 도입 검토에 사용할 **실제 3D 물류 시뮬레이터**를 만든다. 사용자는 창고 안에서 이동, 상하차, 정체와 충전을 공간적으로 확인하고, 대수와 운영안을 바꿔 생산성과 문제점을 비교한다.

대표 공장 DWG는 제공되지 않는다. 초기에는 임의 창고와 생성한 CAD 파일을 사용한다. 사용자의 참고 이미지는 랙·팔레트가 있는 창고에서 로봇이 경로를 따라 움직이는 형태다. 수치 대시보드만으로 이 요구를 충족했다고 판단하지 않는다.

## 이번 단계: 개발 하네스 H0

- 설치·실행·정적 검사·시뮬레이션 테스트·브라우저 테스트·CI를 반복할 수 있는 저장소.
- 미터 단위의 절차 생성 3D 창고, 랙, 팔레트, AMR.
- 한 AMR의 `이동 → 상차 → 운반 → 하차` 수명주기.
- 실제 엔진 상태를 보여주는 팔레트 위치, 작업 상태, 운행 재생.
- JSON 입력 검증, 저장·불러오기, headless 실행과 기준 결과 비교.
- 다음 개발자가 무엇을 어디에 추가하고 무엇으로 검증할지 알 수 있는 문서.

H0는 전체 물류 검토 MVP 완성이 아니다. 단일 AMR의 가시적 동작과 개발 루프를 검증하는 시작점이다.

## 첫 물류 검토 MVP의 완료 조건

1. 합성 DXF를 불러와 레이어와 단위를 확인한다.
2. 설비, 작업 지점, 운행 경로와 일방통행을 지정한다.
3. 여러 AMR이 같은 운반 작업을 처리하며 공유구간·교차로에서 기다린다.
4. 동일 작업 입력으로 3대와 6대의 한 교대 운행을 비교한다.
5. 지연된 작업을 선택하면 해당 시각의 로봇 위치와 대기 원인을 3D에서 확인한다.
6. 입력·운영 규칙·시드·측정 기간·미완료 작업 처리 방식이 결과와 함께 저장된다.

## 단계적으로 추가할 기능

대기행렬과 공간 점유를 검증한 뒤 대수 비교를 추가한다. 충전은 주행·대기·작업 소비 모델과 포트 점유를 명시하고 추가한다. 무인지게차는 AMR과 다른 조향, 전후진, 회전반경, 팔레트 진입·포크 작업 모델을 가진다. 2D CAD의 선을 벽이나 랙으로 자동 해석하는 기능은 별도의 데이터 품질 문제로 다룬다.

제조사 관제, ROS/SLAM, 센서, 정밀 접촉 물리, 포토리얼 렌더링은 필요성이 확인된 뒤 확장한다. 현재 목표는 운영 검토이며, 실제 생산성 판단에는 현장 데이터와의 보정이 필요하다.
